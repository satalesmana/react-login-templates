LANGKAH 3 - BUAT TABEL "dompet" (SQL)
=====================================================================
Buka menu "SQL Editor" -> "New query", tempel SQL di bawah, klik RUN.

PENTING - BEDA DENGAN SQL DI BLOG:
  a) Di blog kurang satu KOMA setelah "updated_at ... now()".
     Tanpa koma, SQL error.
  b) Nama kolom userId, cardBackground, cardColor di sini diberi
     tanda kutip ganda ("userId"). Kenapa?
     PostgreSQL otomatis mengubah nama tanpa kutip menjadi huruf
     kecil semua: userId -> userid. Akibatnya kode aplikasi yang
     mengirim { userId: ... } akan error "Could not find the
     'userId' column". Dengan tanda kutip, huruf besarnya tetap.

---------------------------------------------------------------------
-- 1. Buat tabel dompet
create table dompet (
  id serial primary key,
  "userId" text not null,
  name text not null,
  balance integer not null default 0,
  "cardBackground" text not null,
  "cardColor" text not null,
  updated_at timestamptz default now(),
  created_at timestamptz default now()
);

-- 2. Izin akses lewat API (aman dijalankan walau sudah otomatis)
grant select on public.dompet to anon;
grant select, insert, update on public.dompet to authenticated;
grant usage, select on sequence public.dompet_id_seq to authenticated;

-- 3. Nyalakan Row Level Security (RLS)
alter table dompet enable row level security;

-- 4. Aturan (policy): siapa boleh apa
create policy "dompet bisa dibaca"
  on dompet
  for select
  to anon, authenticated
  using (true);

create policy "user login boleh menambah dompet"
  on dompet
  for insert
  to authenticated
  with check (true);

create policy "user login boleh mengubah dompet"
  on dompet
  for update
  to authenticated
  using (true)
  with check (true);
---------------------------------------------------------------------

Penjelasan singkat:
  - id serial          -> nomor otomatis 1, 2, 3, ...
  - "userId"           -> id akun pemilik dompet (dari Supabase Auth)
  - balance integer    -> saldo. Batas integer = 2.147.483.647
                          (sekitar 2,1 miliar).
  - "cardBackground"   -> warna kartu, contoh "#312E81"
  - "cardColor"        -> warna huruf, contoh "#FFFFFF"
  - RLS                -> "satpam" tabel. Kalau RLS ON tapi tidak ada
                          policy, SEMUA akses ditolak. Policy di atas
                          mengizinkan: semua orang membaca, hanya user
                          yang login boleh menambah/mengubah.

Cek hasilnya: buka menu "Table Editor", harus ada tabel "dompet".

KALAU KAMU SUDAH TERLANJUR membuat tabel dengan SQL blog (tanpa
kutip), hapus dulu lalu jalankan SQL di atas lagi:
  drop table dompet;

  process.env.EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY!;

export const supabase = createClient(supabaseUrl, supabasePublishableKey, {
  auth: {
    ...(Platform.OS !== "web" ? { storage: AsyncStorage } : {}),
    autoRefreshToken: true,
    persistSession: true,
    detectSessionInUrl: false,

if (Platform.OS !== "web") {
  AppState.addEventListener("change", (state) => {
    if (state === "active") {
      supabase.auth.startAutoRefresh();
    } else {
      supabase.auth.stopAutoRefresh();
    }
  });
}

  // Kembali ke login tanpa membuat halaman login dobel
  const goToLogin = () => {
    if (router.canGoBack()) {
      router.back();
    } else {
      router.replace("/login");
    }
  };

  const handleRegister = async () => {
    if (loading) return;

    const newErrors = { fullName: "", email: "", password: "" };
    const emailTrim = email.trim();

    if (fullName.trim() === "") {
      newErrors.fullName = "Please enter your full name !";
    }

    if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(emailTrim)) {
      newErrors.email = "Please enter valid email !";
    }

    if (password.length < 6) {
      newErrors.password = "Password must be at least 6 characters !";
    }

    setErrors(newErrors);

    const hasError = Object.values(newErrors).some((msg) => msg !== "");
    if (hasError) return;

    setLoading(true);
    const { data, error } = await supabase.auth.signUp({
      email: emailTrim,
      password: password,
      options: {
        data: { full_name: fullName.trim() },
      },
    });
    setLoading(false);

    if (error) {
      setErrors({ ...newErrors, email: error.message });
      return;
    }

    if (data.session) {
      // Supabase langsung me-login-kan user baru.
      // Kita logout dulu supaya user login sendiri di halaman Login.
      await supabase.auth.signOut();
      Alert.alert("Berhasil", "Akun berhasil dibuat, silakan login.");
    } else {
      Alert.alert("Cek Email", "Silakan cek email kamu untuk verifikasi.");
    }
    goToLogin();
  };

import { useRouter } from "expo-router";
import { useEffect, useState } from "react";
import { ScrollView, Text, View } from "react-native";
import MyButton from "../components/MyButton";
import { supabase } from "../lib/supabase";

export default function Main() {
  const router = useRouter();
  const [email, setEmail] = useState("");
  const [fullName, setFullName] = useState("");

  // Jalan sekali saat halaman dibuka
  useEffect(() => {
    supabase.auth.getUser().then(({ data: { user } }) => {
      if (!user) {
        router.replace("/login");
        return;
      }
      setEmail(user.email ?? "");
      setFullName(user.user_metadata.full_name ?? "");
    });
  }, [router]);

  const handleLogout = async () => {
    await supabase.auth.signOut();
    router.replace("/login");
  };

  const namaTampil = fullName || email;

  return (
    <View className="flex-1 bg-white">
      <ScrollView
        className="flex-1"
        contentContainerClassName="flex-grow px-[28px] pt-[70px] pb-[40px]"
      >
        {/* Sapaan */}
        <Text className="text-[14px] text-gray-500">Selamat datang,</Text>
        <Text className="mt-1 text-[28px] font-semibold">{namaTampil}</Text>

        {/* Kartu profil */}
        <View className="mt-8 flex-row items-center rounded-[10px] bg-[#0B6EFE] p-5">
          <View className="h-[60px] w-[60px] items-center justify-center rounded-full bg-white">
            <Text className="text-[24px] font-bold text-[#0B6EFE]">
              {namaTampil.charAt(0).toUpperCase()}
            </Text>
          </View>
          <View className="ml-4 flex-1">
            <Text className="text-[18px] font-bold text-white">
              {namaTampil}
            </Text>
            <Text className="mt-1 text-[13px] text-white">{email}</Text>
            <Text className="mt-1 text-[13px] text-white">240444020025</Text>
            <Text className="mt-1 text-[13px] text-white">
              Mahasiswa Manajemen Informatika
            </Text>
          </View>
        </View>

        {/* Kartu info */}
        <View className="mt-5 rounded-[10px] border border-[#9CA3AF] p-5">
          <Text className="text-[16px] font-semibold">Status</Text>
          <Text className="mt-2 text-[14px] text-gray-600">

        </View>

        {/* Tambah dompet */}

  const [nama, setNama] = useState("");
  const [saldo, setSaldo] = useState(0);
  const [desain, setDesain] = useState(DESAIN_KARTU[0]);
  const [huruf, setHuruf] = useState(WARNA_HURUF[0]);
  const [error, setError] = useState("");
  const [loading, setLoading] = useState(false);

  // Warna teks di kartu mengikuti pilihan "Warna Huruf"
  const warnaTeks = { color: huruf.warna };

  const handleSimpan = async () => {
    if (loading) return;

    if (nama.trim() === "") {
      setError("Nama dompet wajib diisi !");
      return;
    }
    setError("");
    setLoading(true);

    // Ambil akun yang sedang login
    const {
      data: { user },
    } = await supabase.auth.getUser();

    if (!user) {
      setLoading(false);
      router.replace("/login");
      return;
    }

    // Simpan ke tabel dompet
    const { error: insertError } = await supabase.from("dompet").insert([
      {
        userId: user.id,
        name: nama.trim(),
        balance: saldo,
        cardBackground: desain.warna,
        cardColor: huruf.warna,
      },
    ]);
    setLoading(false);

    if (insertError) {
      Alert.alert("Gagal menyimpan", insertError.message);
      return;
    }

    Alert.alert("Berhasil", "Dompet berhasil disimpan.");
    router.back();
  };

  return (
    <View className="flex-1 bg-[#F7F7FD]">
      {/* Header */}
      <View className="flex-row items-center px-[20px] pt-[50px] pb-[12px]">
        <Pressable onPress={() => router.back()} className="mr-3 px-2">
          <Text className="text-[30px] text-black">‹</Text>
        </Pressable>
        <Text className="text-[18px] font-semibold">Tambah Dompet</Text>
      </View>

      <ScrollView
        className="flex-1"
        contentContainerClassName="px-[20px] pb-[40px]"
        keyboardShouldPersistTaps="handled"
      >
        {/* Kartu preview */}
        <View
          className="rounded-[16px] p-5"
          style={{ backgroundColor: desain.warna }}
        >
          <View className="flex-row items-center justify-between">
            <View className="h-[18px] w-[26px] rounded-[4px] bg-[#FACC15]" />
            <View className="flex-row items-center rounded-full bg-black/30 px-3 py-1">
              <View className="mr-2 h-[6px] w-[6px] rounded-full bg-[#4ADE80]" />
              <Text className="text-[10px] font-bold text-white">
                PAYNEX E-WALLET
              </Text>
            </View>
          </View>

          <Text className="mt-6 text-[10px]" style={warnaTeks}>
            SALDO TERSEDIA
          </Text>
          <Text className="mt-1 text-[26px] font-bold" style={warnaTeks}>
            Rp {formatRupiah(saldo)}
          </Text>

          <View className="mt-6 flex-row items-end justify-between">
            <View className="flex-1">
              <Text className="text-[10px]" style={warnaTeks}>
                NAMA DOMPET
              </Text>
              <Text
                className="mt-1 text-[18px] font-semibold"
                style={warnaTeks}
                numberOfLines={1}
              >
                {nama.trim() || "Dompet Utama"}
              </Text>
            </View>
            <View className="items-end">
              <Text className="text-[11px] font-bold" style={warnaTeks}>
                •••• 9021
              </Text>
              <Text className="mt-1 text-[9px]" style={warnaTeks}>
                VALID THRU 12/29
              </Text>
            </View>
          </View>
        </View>

        {/* Nama dompet */}
        <View className="mt-6 flex-row items-center justify-between">
          <Text className="text-[15px] font-semibold">Nama Dompet</Text>
          <Text className="text-[11px] text-gray-500">Wajib diisi</Text>
        </View>
        <TextInput
          className={`mt-2 h-[44px] rounded-full bg-[#EEF0FB] px-4 text-[15px] text-black ${
            error ? "border border-[#E57373]" : ""
          }`}
          placeholder="Dompet Utama"
          placeholderTextColor="#9CA3AF"
          value={nama}
          onChangeText={setNama}
        />
        {error !== "" && (
          <Text className="mt-1 text-[12px] text-[#E57373]">{error}</Text>
        )}

        {/* Pilihan cepat nama */}
        <ScrollView
          horizontal
          showsHorizontalScrollIndicator={false}
          className="mt-3"
          contentContainerClassName="gap-2"
        >
          {KATEGORI.map((item) => (
            <Pressable
              key={item}
              onPress={() => setNama(item)}
              className="rounded-full bg-[#E4E7F7] px-4 py-2 active:opacity-70"
            >
              <Text className="text-[13px] text-gray-700">{item}</Text>
            </Pressable>
          ))}
        </ScrollView>

        {/* Saldo awal */}
        <View className="mt-6 flex-row items-center justify-between">
          <Text className="text-[15px] font-semibold">Saldo Awal</Text>
          <Text className="text-[11px] font-semibold text-[#047857]">
            Bebas Biaya Admin
          </Text>
        </View>
        <View className="mt-2 flex-row items-center rounded-[12px] bg-[#EEF0FB] px-4">
          <Text className="mr-2 text-[16px] font-bold">Rp</Text>
          <TextInput
            className="h-[52px] flex-1 text-[26px] font-bold text-black"
            placeholder="0"
            placeholderTextColor="#000000"
            keyboardType="number-pad"
            value={saldo === 0 ? "" : formatRupiah(saldo)}
            onChangeText={(text) => setSaldo(Number(text.replace(/\D/g, "")))}
          />
        </View>
        <Text className="mt-2 text-[11px] text-gray-600">
          Saldo saat dompet baru ini dibuat (default Rp 0).
        </Text>

        <View className="mt-3 flex-row gap-2">
          {TAMBAH_SALDO.map((item) => (
            <Pressable
              key={item.label}
              onPress={() => setSaldo(saldo + item.nilai)}
              className="flex-1 items-center rounded-full bg-[#EEF0FB] py-2 active:opacity-70"
            >
              <Text className="text-[13px] font-semibold text-[#312E81]">
                {item.label}
              </Text>
            </Pressable>
          ))}
        </View>

        {/* Desain kartu */}
        <View className="mt-6 flex-row items-center justify-between">
          <Text className="text-[15px] font-semibold">Pilihan Desain Kartu</Text>
          <Text className="text-[11px] text-gray-500">{desain.nama}</Text>
        </View>
        <View className="mt-3 flex-row gap-3">
          {DESAIN_KARTU.map((item) => (
            <Pressable
              key={item.nama}
              onPress={() => setDesain(item)}
              className={`aspect-square flex-1 items-center justify-center rounded-[12px] ${
                desain.nama === item.nama ? "border-2 border-[#3B28CC]" : ""
              }`}
              style={{ backgroundColor: item.warna }}
            >
              {desain.nama === item.nama && (
                <Text className="text-[18px] font-bold text-white">✓</Text>
              )}
            </Pressable>
          ))}
        </View>

        {/* Warna huruf & aksen */}
        <View className="mt-6 flex-row items-center justify-between">
          <Text className="text-[15px] font-semibold">Warna Huruf & Aksen</Text>
          <Text className="text-[11px] text-gray-500">{huruf.label}</Text>
        </View>
        <View className="mt-3 flex-row flex-wrap gap-2">
          {WARNA_HURUF.map((item) => (
            <Pressable
              key={item.nama}
              onPress={() => setHuruf(item)}
              className={`flex-row items-center rounded-full px-4 py-2 ${
                huruf.nama === item.nama ? "bg-[#DDE1FA]" : "bg-[#EEF0FB]"
              }`}
            >
              <View
                className="mr-2 h-[14px] w-[14px] rounded-full border border-gray-300"
                style={{ backgroundColor: item.warna }}
              />
              <Text className="text-[13px] font-semibold">{item.nama}</Text>
            </Pressable>
          ))}
        </View>

        {/* Info */}
        <View className="mt-6 flex-row rounded-[14px] bg-[#EEF0FB] p-4">
          <View className="mr-3 h-[40px] w-[40px] items-center justify-center rounded-[10px] bg-[#6EE7B7]">
            <Text className="text-[18px] font-bold text-[#065F46]">⇄</Text>
          </View>
          <View className="flex-1">
            <Text className="text-[13px] font-semibold">
              Integrasi Transaksi Otomatis
            </Text>
            <Text className="mt-1 text-[11px] text-gray-600">
              Dompet ini siap ditautkan ke akun Anda untuk pencatatan riwayat
              Cash-In (CI) dan Cash-Out (CO) secara real-time.
            </Text>
          </View>
        </View>

        {/* Tombol */}
        <Pressable
          onPress={handleSimpan}
          className="mt-8 h-[52px] items-center justify-center rounded-full bg-[#3B28CC] active:opacity-80"
        >
          <Text className="text-[16px] font-semibold text-white">
            {loading ? "Menyimpan..." : "Simpan Dompet"}
          </Text>
        </Pressable>
        <Pressable onPress={() => router.back()} className="mt-3 items-center py-2">
          <Text className="text-[14px] text-gray-700">Batal</Text>
        </Pressable>
      </ScrollView>
    </View>
  );
}

Penjelasan bagian penting:
  - DESAIN_KARTU, WARNA_HURUF, dll ditulis di LUAR fungsi karena
    isinya tetap (tidak berubah). Lalu ditampilkan dengan .map().
  - .map((item) => (...)) : mengulang setiap isi array menjadi
    tampilan. Lebih rapi daripada menulis 5 Pressable satu per satu.
    key={...} wajib, supaya React bisa membedakan tiap item.
  - useState(DESAIN_KARTU[0]) : pilihan awal = item pertama
    (Indigo Royale). Saat warna lain ditekan, setDesain(item)
    mengubahnya, dan kartu preview ikut berubah otomatis.
  - style={{ backgroundColor: desain.warna }} : warna dari variabel
    tidak bisa ditulis di className, jadi pakai "style".
  - text.replace(/\D/g, "") : buang semua yang BUKAN angka.
    Contoh "1.500.000" -> "1500000", lalu Number() -> 1500000.
  - { error: insertError } : mengganti nama "error" dari Supabase
    menjadi "insertError", supaya tidak tertukar dengan state "error".
  - userId: user.id : dompet ditandai milik akun yang sedang login.
  - Saldo maksimal sekitar 2,1 miliar (batas tipe integer). Lebih dari
    itu, Supabase akan menolak ("out of range").

Perbedaan kecil dengan Figma (wajar untuk tugas ini):
  - Kartu di Figma bergradasi; di sini warna polos (gradasi butuh
    library tambahan expo-linear-gradient).
  - Ikon dompet/kartu di Figma diganti karakter teks (‹ ✓ ⇄), karena
    proyekmu belum memasang library ikon.
  - Tombol Simpan ikut tergulung (scroll), tidak menempel di bawah.

PESAN ERROR                               PENYEBAB & SOLUSI
-----------------------------------------------------------------------
"supabaseUrl is required"                 .env tidak terbaca. Cek:
                                          file ada di style-17/.env,
                                          nama variabel benar, lalu
                                          restart: npx expo start -c

"Invalid login credentials"               Email/password salah, atau
                                          akun belum ada di Supabase.

"Email not confirmed"                     "Confirm email" masih ON.
                                          Matikan (Langkah 2a) atau
                                          centang Auto Confirm User.

"email rate limit exceeded"               Supabase membatasi kirim
                                          email. Matikan "Confirm
                                          email", tunggu sebentar.

"Could not find the 'userId' column       Tabel dibuat TANPA tanda
 of 'dompet'"                             kutip. Jalankan
                                          "drop table dompet;" lalu
                                          SQL Langkah 3 lagi.

"new row violates row-level security      Policy insert belum dibuat,
 policy"                                  atau user belum login.

"permission denied for table dompet"      Jalankan bagian "grant" di
"permission denied for sequence ..."      SQL Langkah 3.

"value is out of range for type integer"  Saldo lebih dari 2,1 miliar.

Garis merah di router.push("/dompet")     Jalankan "npx expo start"
                                          sekali agar daftar halaman
                                          diperbarui.

"Unable to resolve @supabase/supabase-js" Paket belum terpasang.
                                          Ulangi Langkah 4 dari dalam
                                          folder style-17.

--- B1. Policy yang lebih aman ---
Policy dari blog mengizinkan user login menambah/mengubah dompet
SIAPA SAJA. Untuk aplikasi dompet sungguhan, sebaiknya user hanya
boleh mengurus dompetnya sendiri. Jalankan di SQL Editor:

  drop policy "user login boleh menambah dompet" on dompet;
  drop policy "user login boleh mengubah dompet" on dompet;

  create policy "hanya pemilik boleh menambah"
    on dompet for insert to authenticated
    with check (auth.uid()::text = "userId");

  create policy "hanya pemilik boleh mengubah"
    on dompet for update to authenticated
    using (auth.uid()::text = "userId")
    with check (auth.uid()::text = "userId");

auth.uid() = id akun yang sedang login. Artinya: baris hanya boleh
ditambah/diubah kalau "userId"-nya sama dengan akun yang login.

--- B2. Tampilkan daftar dompet di Main ---
Ide (pakai contoh "get data" dari blog):

  const { data, error } = await supabase
    .from("dompet")
    .select()
    .eq("userId", user.id)
    .order("balance", { ascending: false });

Simpan "data" ke state (useState), lalu tampilkan dengan .map()
seperti di dompet.tsx. Supaya daftar diperbarui setelah kembali dari
halaman Tambah Dompet, pelajari useFocusEffect dari expo-router.
