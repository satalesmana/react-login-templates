# style-26 — Login Template

Replikasi template Figma style 26: alur auth 3 layar
(Welcome → Login → Register) dengan warna ungu `#4E0189`.

## Cara jalanin

```bash
npm install
npx expo install @expo/vector-icons
npx expo start
```

Lalu scan QR pakai Expo Go, atau jalanin di emulator.

## Struktur

- `src/app/index.tsx` — layar Welcome
- `src/app/login.tsx` — layar Login
- `src/app/register.tsx` — layar Register
- `src/components/MySocialButton.tsx` — tombol GitHub / GitLab
- `assets/images/motorcycle.png` — ilustrasi layar Welcome
